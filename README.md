# CodeMe

JavaScript learning material: small browser games and algorithm exercises. No build step.

Open `index.html` for an overview of the browser projects.

## Contents

| Folder | What's inside |
| --- | --- |
| `Basics/` | Lessons plus PigGame, GuessNumber, ModalWindow, Countdown |
| `BasicAlgo/` | Small array, string and object exercises |
| `IntermediateJS/` | Algorithm challenges (fibonacci, pair, spinal tap case, ...) |
| `Challenges/` | Football data, Caesar cipher, palindrome, roman numbers, cash register |
| `DataStructures/` | Sets, maps, destructuring, spread/rest, strings, loops |
| `OOP/` | Prototypes, inheritance, closures, `map`/`filter`/`reduce` |
| `BehindScenes/` | How JavaScript works under the hood |

## Run a file

Browser projects: open the folder's `index.html`.
Console exercises: `node path/to/file.js`
